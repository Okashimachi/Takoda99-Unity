# たこ焼き調理アニメーション 調整ガイド

アート・企画担当がアニメーションの速さや動きの大きさを調整するための手引き。
**コードを触る必要はありません。** すべて Unity の Inspector から数値を変えるだけで調整できます。

---

## 1. どこを開けばいいか

調整する数値は**1つのファイルに全部まとまっています**。

```
Project ウィンドウ → Assets/Settings/CookingAnimationSettings
```

これをクリックすると、Inspector に全パラメータが並びます。**ここ以外に数値は書かれていません。**
「もっと手の動きを速くしたい」「盛り付けの判定を甘くしたい」は、すべてこのファイルの中で完結します。

> ⚠️ Play 中に変えた値は Play を止めると元に戻ります。
> **確定させたい値は Play を止めてから入力**してください。
> （動きを見ながら詰めたいときは Play 中に触ってよいですが、良い値をメモして、止めてから入れ直してください）

---

## 2. パラメータの読み方

### 単位のルール

| 末尾 | 単位 | 例 |
|---|---|---|
| `〜Ms` | **ミリ秒**（1000 = 1秒） | `serveMs = 380` → 0.38秒かけて提供する |
| `〜Offset` / `〜OffsetX` / `〜OffsetY` | **ピクセル**（画面上の移動量） | `handMissOffsetX = 10` → 左右に10px揺れる |
| `〜Scale` | **倍率**（1 = 等倍） | `serveEndScale = 0.6` → 皿が6割の大きさまで縮む |
| `〜Ratio` | **割合**（0〜1） | `cookedProgressRatio = 0.8` → 8割打ったら焼き上がる |
| `〜Kpm` | **1分あたりの打鍵数** | `minKpm = 120` → 毎分120打（＝毎秒2打）以上 |

### 尺の目安

プレイヤーは最速で **1文字あたり100〜130ms** で打ちます。
**1打鍵ごとに起きる演出（手・生地・焼き）を150ms以上にすると、次の打鍵に追い越されて動きが飛びます。**
逆に、8個ごとにしか起きない提供演出は長くても問題ありません。

| 起きる頻度 | 該当する演出 | 推奨する尺 |
|---|---|---|
| 1打鍵ごと | 手の反応、生地投入、焼き上がり | **150ms以下** |
| 8個ごと | 舟皿へ飛ばす、提供 | 長くてよい |

## 3. パラメータ一覧

Inspector 上の見出しごとに並んでいます。

### 手：打鍵ごとの反応

キーを打つたびに手が縦に小さく1往復します。

| 項目 | 既定値 | 意味 | 大きくすると |
|---|---|---|---|
| `Hand Key Duration Ms` | 50 | 1往復の尺 | ゆっくり動く。150を超えると打鍵に追い越される |
| `Hand Key Offset Y` | -12 | 下げる量（px） | 大きく振りかぶる。**マイナスが下方向**（プラスにすると上に跳ねます） |

### 手：ミス反応

ミスしたときだけ、手が横に1往復します。**打鍵ごとの反応より優先**され、同時には出ません。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Hand Miss Duration Ms` | 70 | 1往復の尺 |
| `Hand Miss Offset X` | 10 | 左右に振れる量（px） |

### 窪み：生地投入

新しいたこ焼きを焼き始めるとき、生地が落ちて広がります。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Batter Fall Ms` | 60 | 落ちてくる尺 |
| `Batter Spread Ms` | 40 | 落ちたあと広がる尺 |
| `Batter Fall Start Scale` | 1.3 | 落下開始時の大きさ。大きいほど「上から降ってきた」感じが強い |

### 窪み：焼き上がり

**単語を打ち切った瞬間に**、生地（Raw）から焼き（Done）へ切り替わります。打っている途中では変わりません。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Cooked Fade Ms` | 90 | 生地→焼きのクロスフェードの尺。同じ尺でたこ焼き自体もひっくり返る |

### 手・窪み：ひっくり返し演出 ★重要

**単語を打ち切った瞬間、手が打ち終えたたこ焼きの位置まで動いてひっくり返し、続けて次のお題が使う
穴まで動いて、そこで止まります。** 同時にたこ焼き自身も回転して、ひっくり返したように見せます。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Hand Flip Duration Ms` | 160 | 手が「打ち終えた穴」→「次のお題の穴」と動く尺（2区間で半分ずつ） |
| `Takoyaki Flip Rotation Degrees` | 360 | たこ焼きが回転する角度。360 = 1回転して元の向きに戻る |

> **手は元の場所へは戻りません。** お題が変わるたびに手の「定位置」自体が次の穴の近くへ更新されます。
> 打鍵ごとの反応（2番）・ミス反応（3番）は、この更新された定位置を基準に揺れます。
> ずっと同じ場所で手が動いているように見えたら、この演出が正しく動いていない可能性があります。

> この演出は、打鍵ごとの反応（2番）・ミス反応（3番）より**後に起きるため、それらを上書きします**。
> 単語の最後の1打を打った瞬間は、必ずこのひっくり返しだけが再生されます。

### 舟皿：盛り付けの出来 ★重要

**1注文（8個ぶん）を打つ間のミス率**で、盛り付けの絵が3段階に変わります。
たこ焼き1個ずつではなく、**皿全体で1回だけ**判定します。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Tray Clean Max Miss Ratio` | 0 | これ以下なら **きれい**。0 = ノーミスのときだけ |
| `Tray Normal Max Miss Ratio` | 0.15 | これ以下なら **ふつう**。超えたら **汚い** |
| `Tray Served Fade Ms` | 80 | 盛り付け絵が現れる尺 |

**判定のしかた**

```
ミス率 = ミスした打鍵数 ÷ 全打鍵数

例）100回打って3回ミス → ミス率 0.03
    0.03 は 0（きれいの上限）を超え、0.15（ふつうの上限）以下 → 「ふつう」
```

回数ではなく**割合**なのは、注文の個数も単語の長さもサーバーが決めるためです。
回数で判定すると、長い単語が来た注文だけ不利になってしまいます。

**調整の目安**

| やりたいこと | 変え方 |
|---|---|
| きれいをもう少し出やすくしたい | `Tray Clean Max Miss Ratio` を 0.02〜0.03 にする |
| 汚いをもっと出したい | `Tray Normal Max Miss Ratio` を 0.08 くらいに下げる |
| 汚いをあまり出したくない | `Tray Normal Max Miss Ratio` を 0.25 くらいに上げる |

### 完成：舟皿へ

8個打ち終わった瞬間、鉄板の上のたこ焼きが**一斉に**舟皿へ飛びます。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Fly Rise Ms` | 90 | 窪みから浮き上がる尺 |
| `Fly Arc Ms` | 80 | 弧を描いて飛ぶ尺 |
| `Fly Land Ms` | 50 | 皿へ着地する尺 |
| `Fly Apex Height Scale` | 1.4 | 弧の高さ。窪み1個の高さの何倍まで上がるか |
| `Fly Stagger Ms` | 40 | **1個ずつ出発をずらす量。** 0 にすると8個が塊で飛びます |

> 8個ぶんの合計時間 ≒ `Fly Stagger Ms × 7 + (Rise + Arc + Land)`
> 既定値なら 40×7 + 220 = **約500ms**。ここを短くしたいときは `Fly Stagger Ms` を下げてください。

### 舟皿：提供

8個が皿に乗ったあと、客へ差し出して新しい皿が出ます。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Serve Delay Ms` | 180 | 盛り付けてから動き出すまでの**間（ま）** |
| `Serve Ms` | 380 | 皿が縮みながらスライドして消える尺 |
| `Tray Fade In Ms` | 220 | 新しい空の皿が現れる尺 |
| `Tray Cross Overlap Ms` | 50 | 消えるのと現れるのを重ねる時間 |
| `Serve Slide Offset` | X:50 Y:100 | 皿がどの方向へ動くか（px）。**客のいる方向に向ける** |
| `Serve End Scale` | 0.6 | 消えるときの縮み具合 |

### 打鍵速度 → 使う穴数・使う穴の巡回 ★重要

**速く打つ人ほど、鉄板の穴をたくさん使って生地を仕込みます。**
**試合が始まった直後・客が入れ替わった直後は、必ず下限（`Speed Tiers` の Element 0 が示す穴数。既定8個）から始まります。**
そこから、その客に対する打鍵速度に応じて穴数が増えていきます（客が変わるたびに測り直します）。

**どの物理的な穴を使うかは、いま使っている穴数の範囲を巡回します。** 1つめ→2つめ→…→穴数個目、と
進み、そこを超えたらまた1つめに戻ります。**この巡回位置は客が変わっても引き継がれます。**
毎回同じ左上の穴だけが動き続けることはありません（この動きに調整できるパラメータはありません。
常に1個ずつ進む決まりです）。

| 項目 | 既定値 | 意味 |
|---|---|---|
| `Speed Tiers` | 4段階 | 速度としきい値の表（下記） |
| `Speed Window Keys` | 20 | 速度を測るのに使う直近の打鍵数。小さいほど反応が速く、荒れる |
| `Speed Tier Drop Hold Ms` | 1500 | **段階が下がるまでの猶予。** 上がるのは即座、下がるのはこの時間待つ |

`Speed Tiers` の中身：

| 要素 | Min Kpm | Slot Count | 意味 |
|---|---|---|---|
| Element 0 | 0 | 8 | 遅い（〜毎分120打）→ 8穴 |
| Element 1 | 120 | 12 | 毎分120打（毎秒2打）以上 → 12穴 |
| Element 2 | 200 | 18 | 毎分200打（毎秒3.3打）以上 → 18穴 |
| Element 3 | 280 | 24 | 毎分280打（毎秒4.7打）以上 → 全24穴 |

**変えるときの決まりごと**

1. **先頭（Element 0）の `Min Kpm` は必ず 0 にする**（どの速度にも当てはまらない状態を作らない）
2. **`Min Kpm` は上から昇順に並べる**（0 → 120 → 200 → 280）
3. `Slot Count` は 1〜24 の範囲

段階を増やしたいときは `Size` を 5 などに増やして、行を足してください。減らすときも同様です。

> `Speed Tier Drop Hold Ms` を 0 にすると、打鍵が一瞬途切れただけで穴がガクッと減ってチラつきます。
> 1000〜2000 の範囲を推奨します。

> ちなみに、穴数が増え始めるのは `Speed Window Keys`（既定20）ぶん打ってからです。
> それより前は KPM を計算に使いません（数打だけで速度を判定すると、たまたま連打が
> 詰まっただけで異常に高い値が出て、試合開始直後に穴が全開放されてしまうため）。

## 4. 絵の差し替えかた

数値ではなく**画像**を差し替えたいときは、以下の場所です。

### 鉄板のたこ焼き（生地・焼き）

```
Project → Assets/MainStoreCanvas/Takoyaki.prefab をダブルクリック
  ├── TakoyakiRaw   の Image → Source Image   ← 生地の絵
  └── TakoyakiDone  の Image → Source Image   ← 焼き上がりの絵
```

Prefab を1回直すと、鉄板の24個すべてに反映されます。

> たこ焼き1個ずつが「きれい／汚い」で変わることはありません（皿だけが変わります）。
> なので Raw と Done の**2枚だけ**用意すれば足ります。

### 舟皿

```
Hierarchy → MainGame シーン → root/MainStoreCanvas/Main/MainStore/TrayRoot を選択
  Inspector の TrayView コンポーネント：
    Tray Clean Sprite   ← きれいな盛り付け（現在 takoyaki_tray_success）
    Tray Normal Sprite  ← ふつうの盛り付け（現在 takoyaki_tray_good）
    Tray Dirty Sprite   ← 汚い盛り付け  （現在 takoyaki_tray_fail）

  子の TrayEmpty の Image → Source Image   ← 空の舟皿の絵
```

### 手

```
Hierarchy → root/MainStoreCanvas/Main/MainStore/HandRoot/RightHandPivot/Hand を選択
  Image → Source Image   ← 手の絵（現在 Hand.png）
```

**手の向きを左右反転したいとき**は、`Hand` の `Rect Transform` → `Scale` の **X を -1** にしてください。
`RightHandPivot` や `HandRoot` の Scale は触らないでください（揺れの向きがおかしくなります）。

> `HandView` コンポーネントの `Hand Image` 欄には、この `Hand` オブジェクト自身が割り当ててあります。
> ひっくり返し演出で「手の**左下角**をたこ焼きに合わせる」ための、手の大きさの参照に使っています。
> 手の絵のサイズ（Rect Transform の Width / Height）を変えると、この位置合わせも自動でついてきます。
> **`Hand Image` の割り当てを外さないでください**（外すと角合わせができず、手の中心がたこ焼きに合ってしまいます）。

## 5. 位置を動かしたいとき

絵の**置き場所**は Inspector の数値ではなく、シーン上の配置で決まります。

| 動かしたいもの | Hierarchy 上の場所 | 動かすオブジェクト |
|---|---|---|
| 手の定位置 | `MainStore/HandRoot` | **`HandRoot`**（`RightHandPivot` ではない） |
| 舟皿の位置 | `MainStore/TrayRoot` | **`TrayRoot`** |
| 玉が飛んでくる着地点 | `TrayView` の `Landing Point` | 未割り当てなら `TrayRoot` の中心。ずらしたいときだけ空の子オブジェクトを作って割り当てる |
| 鉄板の穴の並び | `MainStore/Takoyakis/FirstLine`〜`FourthLine` | 各行オブジェクト |

> ⚠️ **`RightHandPivot` は動かさないでください。** これは揺れアニメーション専用の入れ物で、
> ここを動かすと手の定位置がずれていきます。手の位置は必ず親の `HandRoot` で調整してください。
>
> ⚠️ 同じく `FlyLayer` も動かさないでください。飛んでいる玉の入れ物です。

## 6. 動きを確認する

サーバーに繋がなくても、1人で動きを確認できます。

```
1. Hierarchy で空の GameObject を作る（右クリック → Create Empty）
2. Inspector の Add Component で「Cooking Test Driver」を追加
3. 以下を割り当てる
     Takoyaki Stand ← MainStore/Takoyakis をドラッグ
     Hand           ← MainStore/HandRoot をドラッグ
4. Play を押す
```

`Cooking Test Driver` の設定：

| 項目 | 意味 |
|---|---|
| `Keys Per Word` | 1個のたこ焼きを焼くのに必要な打鍵数（7くらいが実際に近い） |
| `Order Count` | 1回の注文の個数（8） |
| `Key Interval Ms` | 打鍵の間隔。**130 が最速の人、300 くらいが遅い人** |
| `Miss Rate` | ミスの混ざる確率（0〜1）。盛り付けの出来を確認するときに上げる |
| `Auto Type` | ON で自動再生。OFF にすると Space キーで1打ずつ進む（Shift＋Space でミス） |

**確認したいことと、その設定**

| 確認したいこと | 設定 |
|---|---|
| 最速で打たれても演出が破綻しないか | `Key Interval Ms` = 100 |
| 穴が増減するか | Play 中に `Key Interval Ms` を 300 → 100 → 300 と動かす |
| 汚い盛り付けが出るか | `Miss Rate` = 0.3 |
| きれいな盛り付けが出るか | `Miss Rate` = 0 |

> ⚠️ **確認が終わったら、この GameObject は必ず削除してください。**
> 残したままだと、本番の入力と二重に鉄板が動きます。

## 7. 困ったとき

| 症状 | 原因として多いもの |
|---|---|
| 何も動かない | `CookingAnimationSettings` が各コンポーネントに割り当てられていない。Console に赤いエラーが出ているはず |
| 玉が飛ばない | `Takoyakis` の `Flying Animator` / `Tray` が未割り当て |
| 手が動かない | `HandView` の `Pivot` に `RightHandPivot` を割り当て忘れ |
| ひっくり返しで手がたこ焼きの中心に来る（左下角に来ない） | `HandView` の `Hand Image` が未割り当て |
| 生地が試合開始直後から24個ある | `Speed Tiers` の Element 0 の `Min Kpm` が 0 になっていない、または `Speed Tiers` が空 |
| 焼き上がりが打鍵の途中で始まる／完了とタイミングが合わない | 過去のバージョンの名残。最新のスクリプトでは単語を打ち切った瞬間にしか切り替わらない |
| 生地が最初から焼き上がった見た目（Done）になっている | `Takoyaki.prefab` の `TakoyakiSlotView` で `Raw` / `Done` の割り当てが入れ替わっていないか確認（過去に取り違えていた事故があった。直し済みだが、Prefab を作り直した場合は要確認） |
| いつも左上の穴しか動かない | `TakoyakiStandView` が古いバージョンのまま（穴の巡回機能が入っていない）。最新のスクリプトに更新されているか確認 |
| 手の位置がだんだんずれる | `RightHandPivot` を直接動かしてしまった。`HandRoot` で調整し、`RightHandPivot` の Position は 0,0 に戻す |
| 玉が途中で切れて見える | `FlyLayer` に `Mask` か `RectMask2D` が付いている。外す |
| 盛り付けの絵が出ない | `TrayView` の Sprite 3枠が未割り当て |
| 穴の数が常に24個 | `Speed Tiers` が空、または先頭の `Min Kpm` が 0 になっていない |

**Console に赤いエラーが出ていたら、まずそれを読んでください。** 未割り当ての項目は名指しで表示されます。
